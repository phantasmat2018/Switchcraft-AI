**Switchcraft AI** — сучасний інтелектуальний перемикач клавіатурної розкладки для Windows з українським інтерфейсом, розпізнаванням мови за допомогою штучного інтелекту та повною відсутністю сторонньої телеметрії.

## ✨ Основні можливості

- **Розумне автовиправлення EN / УК / RU**: аналіз слів після натискання пробілу (також підтримується Enter у Scintilla / кодових редакторах) зі збереженням початкового регістру.
- **Штучний інтелект на вибір**:
  - 🧠 **TypeSafe AI** — швидке хмарне розпізнавання мови через захищений API без передачі конфіденційних даних.
  - ⚡ **Laya (локальна модель r4)** — нейромережа mmBERT, яка повністю запускається на вашому ПК (CPU або NVIDIA CUDA) і працює навіть без доступу до інтернету.
  - 📖 **Перевірка словниками** — варіанти, які пропонує ШІ, звіряються з українським і російським словниками Hunspell; вони ж виправляють слова, поки модель завантажується або не впевнена.
- **Активні мови й головна мова**: Будь-яку мову, зокрема англійську, можна вимкнути (активними лишаються щонайменше дві). Перша активна мова — головна: вона має пріоритет у ручному перетворенні неоднозначних слів; порядок змінюють кнопки «Вище» / «Нижче» на сторінці «Мови», а коли вимикається головна мова, Switchcraft пропонує обрати нову головну серед активних. На вимкнену мову автоматичні виправлення не перетворюють; без англійської слова, набрані в англійській розкладці, однаково виправляються на активні мови.
- **Автоматичне перемикання системної розкладки**: після успішного виправлення тексту розкладка клавіатури змінюється автоматично.
- **Безпека та конфіденційність**:
  - Поля введення паролів, менеджери паролів та захищені форми ігноруються автоматично.
  - Жодного журналювання тексту чи збереження набраних паролів на диск.
  - Історія виправлень (до 50 записів) зберігається виключно в оперативній пам'яті поточної сесії.
- **Перевірка оновлень**: кнопка «Перевірити оновлення» в налаштуваннях знаходить найновіший стабільний реліз на GitHub і пропонує відкрити сторінку завантаження. Якщо перевірити не вдалося (немає інтернету, GitHub не відповідає), програма показує причину, а не «найновіша версія». Щоб оновитися, завершіть Switchcraft AI через меню значка в треї й запустіть новий інсталятор — налаштування, автозапуск і модель Laya зберігаються.
- **Швидке скасування**: безпечне повернення тексту комбінацією клавіш (`Ctrl + Alt + Backspace`) або додавання слова до винятків у режимі навчання.
- **Гнучкі налаштування**: списки виключених програм, гарячі клавіші, пошук і додавання власних правил та замін, імпорт та експорт налаштувань у форматі JSON.
- **Сумісність**: перевірено справжнім набором у Chrome і Edge (textarea, input і contenteditable, як у Gmail чи Telegram Web), Блокноті Windows 11, Notepad++ і VS Code — виправлення, збереження правильних слів, перемикання розкладки та скасування гарячою клавішею. В адресному рядку Chrome пошукові запити виправляються, правильно набрані адреси (`google.com`) не змінюються, а адреса, набрана в українській чи російській розкладці (`пщщпдуюсщь`), перетворюється на `google.com` і після пробілу, і після Enter (Enter притримується до 1,5 с, доки адресу не виправлено). Слово, набране одразу після кліку чи перемикання вікна, теж виправляється: поки Switchcraft перевіряє поле, набір лише запам'ятовується, а в полі пароля відкидається. Якщо програма не встигла відповісти на перевірку (Chrome одразу після Ctrl+T), поле вважається ще не перевіреним, а не забороненим, тому перше слово в новій вкладці не губиться. Слово, якого немає в словнику (наприклад, народна форма «зеленеє»), набране в іншій розкладці, виправляється лише тоді, коли сусідні слова речення вже розпізнано як цю мову. Про розкладку, яку Switchcraft не розпізнає, він один раз повідомляє в треї. Мова розкладки визначається за самою розкладкою, тому працюють і мови без власного коду Windows, як-от «Русский (Украина)» чи «English (Ukraine)». Якщо під час заміни слова ви вже друкуєте далі, натискання на мить притримуються й передаються в тому ж порядку одразу після заміни, вже в перемкненій розкладці, тож наступне слово набирається правильною мовою. Швидко набрана без пауз фраза (до восьми слів) виправляється повністю на першій паузі, а не лише останні слова. VS Code без режиму для екранного диктора не надає текст редактора через UI Automation, тому виправлення там пропускаються, а Switchcraft один раз повідомляє про це в треї; увімкніть режим: Shift+Alt+F1 або `"editor.accessibilitySupport": "on"`.

## ⌨️ Стандартні гарячі клавіші

| Дія | Комбінація |
| :--- | :--- |
| **Перетворити виділений текст** | `Ctrl + Alt + Space` |
| **Скасувати останнє автовиправлення** | `Ctrl + Alt + Backspace` |
| **Пауза / Відновити роботу** | `Ctrl + Alt + P` |
| **Виділення → Українська** | `Ctrl + Alt + 1` |
| **Виділення → Англійська** | `Ctrl + Alt + 2` |
| **Виділення → Російська** | `Ctrl + Alt + 3` |

Комбінації клавіш можна змінити в розділі **Налаштування → Гарячі клавіші**.

## 🤖 Локальна модель Laya

Switchcraft AI підтримує роботу з автономною моделлю Laya:
1. Відкрийте **Налаштування → Як визначати мову → Laya · локально**.
2. Якщо модель ще не завантажена, натисніть кнопку **Завантажити й підготувати**.
3. Програма завантажить модель r4 (~599 МБ) з [офіційного релізу](https://github.com/phantasmat2018/Switchcraft-AI/releases/tag/laya-r4), перевірить контрольну суму SHA-256 та налаштує автономне середовище виконання. Якщо раніше було встановлено r3, програма запропонує «Оновити модель»: нову модель буде завантажено й перевірено, а стару після цього видалено. Модель, яку ви підклали самостійно, не замінюється.
4. Доступні режими прискорення: **Автоматично**, **CPU** та **NVIDIA CUDA**. Якщо вільної пам'яті відеокарти менше 1,5 ГБ (її зайняла інша програма, наприклад гра чи тренування моделі), Laya працює на CPU, а статус пояснює чому.

## 🔒 Конфіденційність та збереження даних

* Налаштування користувача зберігаються у теці `%LOCALAPPDATA%\Switchcraft`.
* Усі запити до API TypeSafe шифрують ключ за допомогою Windows DPAPI для поточного користувача.
* Застосунок не надсилає жодної сторонньої телеметрії та аналітики.
